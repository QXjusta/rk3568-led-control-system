# 内核整编步骤指南

## 准备工作

1. **环境要求**
   - Linux操作系统（建议Ubuntu 18.04或更高版本）
   - 安装必要的编译工具：`sudo apt-get install build-essential git gcc-aarch64-linux-gnu gcc-arm-linux-gnueabi`
   - 确保有足够的磁盘空间（至少20GB）

2. **获取完整内核源码**
   - 确保你已经有了完整的RK3568内核源码
   - 我们的驱动已经集成到了内核源码树中

## 整编步骤

### 1. 进入内核源码目录
```bash
cd /path/to/your/kernel
```

### 2. 配置交叉编译环境
```bash
# 设置ARCH和CROSS_COMPILE环境变量
export ARCH=arm64
export CROSS_COMPILE=aarch64-linux-gnu-
# 或者使用Android NDK工具链
export CROSS_COMPILE=/path/to/ndk/toolchains/aarch64-linux-android-4.9/prebuilt/linux-x86_64/bin/aarch64-linux-android-
```

### 3. 配置内核

#### 方法1：使用默认配置
```bash
make rockchip_defconfig
```

#### 方法2：使用已有的.config文件
```bash
# 如果已经有配置文件，可以直接使用
cp /path/to/existing/.config .
make olddefconfig
```

#### 方法3：自定义配置
```bash
# 进入交互式配置界面
make menuconfig
# 在配置界面中确保以下选项被正确设置：
# - Device Drivers > LED Support > LED Class Support
# - Device Drivers > LED Support > LED Support for Yuanzi LED driver
# 保存并退出
```

### 4. 开始编译

#### 编译内核镜像
```bash
make -j$(nproc)
# 编译完成后，内核镜像会生成在：arch/arm64/boot/Image
```

#### 编译设备树
```bash
make dtbs
# 设备树文件会生成在：arch/arm64/boot/dts/rockchip/
# 我们的设备树文件是：rk3568-evb1-ddr4-v10-linux.dtb
```

#### 编译模块
```bash
make modules
# 编译完成后，模块会生成在对应目录下
```

#### 安装模块
```bash
# 创建安装目录
mkdir -p /path/to/rootfs
# 安装模块
make INSTALL_MOD_PATH=/path/to/rootfs modules_install
```

### 5. 准备烧录文件

编译完成后，你会得到以下文件：
- 内核镜像：`arch/arm64/boot/Image`
- 设备树：`arch/arm64/boot/dts/rockchip/rk3568-evb1-ddr4-v10-linux.dtb`
- 模块：安装在`/path/to/rootfs/lib/modules/`目录下

### 6. 烧录内核

#### 使用RK烧录工具
1. **准备烧录工具**
   - 下载并安装RK烧录工具（如Android Tool或rkflashtool）
   - 准备好烧录线和开发板

2. **进入烧录模式**
   - 将开发板连接到电脑
   - 按住烧录按键，然后开机，进入烧录模式

3. **烧录内核**
   - 打开RK烧录工具
   - 选择编译好的内核镜像和设备树文件
   - 点击烧录按钮，等待烧录完成

#### 使用fastboot烧录
```bash
# 进入fastboot模式
adb reboot bootloader
# 烧录内核
fastboot flash boot arch/arm64/boot/Image
# 烧录设备树
fastboot flash dtbo arch/arm64/boot/dts/rockchip/rk3568-evb1-ddr4-v10-linux.dtb
# 重启设备
fastboot reboot
```

## 验证驱动

烧录完成后，启动开发板，验证驱动是否正常工作：

1. **检查驱动是否加载**
```bash
dmesg | grep yuanzi_led
```

2. **检查设备节点**
```bash
ls -la /dev/yuanzi_led
ls -la /sys/class/leds/work/
```

3. **测试LED控制**
```bash
# 开启LED
echo 255 > /sys/class/leds/work/brightness
# 关闭LED
echo 0 > /sys/class/leds/work/brightness
# 设置为心跳模式
echo heartbeat > /sys/class/leds/work/trigger
# 设置为闪烁模式
echo timer > /sys/class/leds/work/trigger
```

## 故障排除

1. **驱动无法加载**
   - 检查dmesg日志，查看错误信息
   - 确认设备树中的compatible属性与驱动匹配
   - 检查GPIO配置是否正确

2. **LED不亮**
   - 检查硬件连接
   - 使用万用表测量GPIO引脚电压
   - 检查内核配置是否启用了LED相关选项

3. **编译失败**
   - 确保交叉编译工具链正确安装
   - 检查内核版本与工具链版本兼容性
   - 清理编译缓存：`make clean`或`make mrproper`

## 注意事项

1. **备份原始内核**
   - 烧录前建议备份原始内核和设备树
   - 确保有恢复机制，如TF卡恢复

2. **内核版本一致性**
   - 确保编译的内核版本与开发板上的Android版本兼容
   - 建议使用与开发板原厂内核相同的版本

3. **调试信息**
   - 编译时可以开启调试信息，便于调试问题：`make EXTRA_CFLAGS="-DDEBUG"`

## 后续开发

如果需要修改驱动，可以按照以下步骤：

1. 修改驱动源码：`drivers/leds/yuanzi_led.c`
2. 重新编译：`make modules`
3. 安装模块：`make INSTALL_MOD_PATH=/path/to/rootfs modules_install`
4. 重新烧录或直接加载模块：`insmod yuanzi_led.ko`

# 驱动特性回顾

1. **支持的工作模式**
   - none：关闭
   - default-on：常亮
   - heartbeat：心跳模式
   - timer：闪烁模式

2. **控制接口**
   - 字符设备：`/dev/yuanzi_led`
   - sysfs：`/sys/class/leds/work/`
   - 物理按键：KEY_VOLUMEUP

3. **设备树节点**
   ```dts
yuanzi_led {
    compatible = "yuanzi,led-driver";
    led-gpios = <&gpio0 RK_PB7 GPIO_ACTIVE_HIGH>;
    led-name = "work";
    led-default-mode = "none";
    status = "okay";
};
   ```

4. **驱动参数**
   - 可以通过模块参数指定GPIO：`insmod yuanzi_led.ko led_gpio=15`
   - 默认GPIO：15（RK_PB7, GPIO0_B7）
