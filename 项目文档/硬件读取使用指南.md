# RK3568开发板LED控制系统使用指南

## 概述

本指南介绍了RK3568开发板上的LED控制系统，该系统包含完整的Android应用和Linux字符设备驱动实现，支持LED控制、按键检测、状态监控等功能。系统采用跨进程通信架构，提供友好的用户界面和稳定的硬件控制能力。

## 项目架构

### 1. Android应用层
- **MainActivity**：主控制界面，提供LED开关、亮度调节、模式选择
- **HardwareTestActivity**：硬件测试界面，提供硬件状态读取和测试功能
- **RK3568HardwareService**：硬件通信服务，支持跨进程通信

### 2. Linux驱动层
- **zhangsan_led.c**：字符设备驱动，实现LED控制和按键检测
- **led-button-overlay.dts**：设备树覆盖文件，配置GPIO引脚
- **Makefile**：驱动编译配置

### 核心功能
- **LED控制**：支持开关、亮度调节、模式切换
- **按键检测**：硬件按键触发LED状态切换
- **状态监控**：实时读取LED和系统状态
- **跨进程通信**：支持硬件服务在独立进程中运行

## 已实现的功能

## 使用方法

### 步骤1：编译和安装驱动
1. 进入`driver`目录：`cd driver`
2. 编译驱动：`make`
3. 安装驱动：`insmod zhangsan_led.ko`
4. 检查设备节点：`ls -la /dev/zhangsan_led`

### 步骤2：启动应用
1. 在RK3568开发板上找到并启动"MyApplication3"应用
2. 应用主界面显示LED控制面板，包含开关、亮度调节、模式选择

### 步骤3：使用主控制功能
在主控制界面，你可以：

1. **LED开关控制**
   - 点击开关按钮控制LED的开启和关闭
   - 实时显示LED当前状态

2. **亮度调节**
   - 使用滑块调节LED亮度（0-100）
   - 亮度值实时显示

3. **模式选择**
   - 选择不同的LED工作模式
   - 支持常亮、闪烁等模式

### 步骤4：硬件测试功能
1. 在主界面点击"硬件测试"按钮进入测试界面
2. 在硬件测试界面，你可以：

   - **测试LED状态**：读取当前LED设备状态
   - **测试GPIO状态**：读取GPIO引脚电平状态
   - **测试系统信息**：读取CPU、内存等系统信息
   - **全面测试**：一次性测试所有硬件功能

## 硬件设备节点说明

### LED字符设备
- **设备路径**：`/dev/zhangsan_led`
- **功能**：LED控制（开关、亮度、模式）和状态读取
- **权限要求**：读写权限（通常需要root权限）
- **IOCTL命令**：
  - `LED_SET_POWER`：设置LED电源状态
  - `LED_SET_BRIGHTNESS`：设置LED亮度
  - `LED_GET_STATE`：获取LED当前状态

### GPIO设备
- **设备路径**：`/sys/class/gpio/`
- **功能**：GPIO引脚状态读取和控制
- **权限要求**：系统级权限
- **实际实现**：通过设备树配置的GPIO引脚

### 系统信息
- **CPU信息**：`/proc/version`、`/proc/cpuinfo`
- **内存信息**：`/proc/meminfo`
- **系统状态**：`/proc/stat`

### 设备树配置
- **设备树文件**：`led-button-overlay.dts`
- **兼容性**：`rockchip,rk3568`
- **GPIO配置**：LED和按键的GPIO引脚映射
- **引脚控制**：上拉/下拉配置

## 代码结构说明

### Android应用层核心类
1. **MainActivity.java**
   - 主控制界面，提供LED开关、亮度调节、模式选择
   - 实时显示LED状态和系统信息
   - 支持硬件测试界面跳转

2. **HardwareTestActivity.java**
   - 硬件测试界面，提供硬件状态读取和测试功能
   - 支持跨进程通信，可独立运行硬件服务
   - 实时显示测试结果和通信状态

3. **RK3568HardwareService.java**
   - 硬件通信服务，支持跨进程通信
   - 封装硬件访问逻辑，提供统一的硬件接口
   - 包含Binder实现，支持远程调用

4. **LEDState.java**
   - LED状态数据类
   - 包含电源状态、亮度、模式等属性
   - 支持序列化和反序列化

### Linux驱动层核心文件
1. **zhangsan_led.c**
   - 字符设备驱动，实现LED控制和按键检测
   - 支持IOCTL命令：LED控制、状态读取
   - 包含按键中断处理，支持硬件按键触发

2. **led-button-overlay.dts**
   - 设备树覆盖文件，配置LED和按键的GPIO引脚
   - 定义引脚映射和控制参数
   - 兼容RK3568开发板

3. **Makefile**
   - 驱动编译配置
   - 包含内核模块编译规则
   - 支持交叉编译

## 实际硬件访问说明

### 实现状态
- **字符设备驱动**：通过`/dev/zhangsan_led`设备节点进行LED控制
- **GPIO访问**：通过设备树配置的GPIO引脚进行状态读取
- **系统信息**：通过`/proc`文件系统读取系统参数
- **跨进程通信**：支持硬件服务在独立进程运行

### 硬件访问流程
1. **驱动加载**：通过`insmod`加载字符设备驱动
2. **设备节点创建**：驱动自动创建`/dev/zhangsan_led`设备节点
3. **权限检查**：应用检查设备节点访问权限
4. **IOCTL控制**：通过IOCTL命令控制LED状态
5. **状态读取**：读取GPIO和系统状态信息

### 权限要求
要访问硬件设备，应用需要以下权限：
- **系统级权限**：root权限，用于访问设备节点
- **设备节点权限**：对`/dev/zhangsan_led`的读写权限
- **GPIO访问权限**：对`/sys/class/gpio/`目录的访问权限
- **系统信息权限**：对`/proc`文件系统的读取权限

## 故障排除

### 常见问题

1. **权限不足错误**
   - 确保应用有足够的权限访问设备节点
   - 检查设备节点的权限设置

2. **设备未找到**
   - 确认设备路径是否正确
   - 检查设备是否已正确连接

3. **数据读取失败**
   - 检查硬件连接状态
   - 确认设备驱动程序正常工作

### 调试方法

1. **查看日志**
   - 使用`adb logcat`查看应用日志
   - 过滤关键字："HardwareTestActivity"、"RK3568"

2. **检查设备节点**
   ```bash
   adb shell ls -la /dev/ | grep -E "(led|gpio)"
   adb shell ls -la /sys/class/gpio/
   ```

3. **测试权限**
   ```bash
   adb shell "ls -la /dev/zhangsan_led"
   adb shell "cat /proc/version"
   ```
