# RK3588 LED驱动编译安装指南

## 一、环境准备

### 1. 安装交叉编译工具链

#### 对于Ubuntu/Debian系统：
```bash
# 安装ARM64交叉编译工具链
sudo apt update
sudo apt install gcc-aarch64-linux-gnu g++-aarch64-linux-gnu

# 安装ARM32交叉编译工具链（可选）
sudo apt install gcc-arm-linux-gnueabihf g++-arm-linux-gnueabihf
```

#### 对于CentOS/RHEL系统：
```bash
sudo yum install gcc-aarch64-linux-gnu gcc-arm-linux-gnueabihf
```

#### 验证安装：
```bash
# 检查ARM64交叉编译器
aarch64-linux-gnu-gcc --version

# 检查ARM32交叉编译器
arm-linux-gnueabihf-gcc --version
```

### 2. 获取RK3588内核源码

从Rockchip官网或GitHub获取对应版本的RK3588内核源码：
```bash
# 示例：克隆RK3588内核源码
git clone https://github.com/rockchip-linux/kernel.git
cd kernel
git checkout rk3588-linux-5.10
```

## 二、驱动编译

### 1. 修改Makefile

编辑`driver/Makefile`，设置正确的内核源码路径和交叉编译器：

```makefile
# 内核源码路径 - 根据实际情况修改
KERNEL_DIR := /path/to/rk3588/kernel

# 对于ARM64架构（RK3588）
ARCH := arm64
CROSS_COMPILE := aarch64-linux-gnu-

# 当前驱动目录
CURRENT_DIR := $(shell pwd)

# 驱动模块名称
MODULE_NAME := zhangsan_led

# 编译目标
obj-m := $(MODULE_NAME).o

# 编译命令
all:
	$(MAKE) -C $(KERNEL_DIR) M=$(CURRENT_DIR) modules

# 清理命令
clean:
	$(MAKE) -C $(KERNEL_DIR) M=$(CURRENT_DIR) clean

# 安装命令
install:
	insmod $(MODULE_NAME).ko

# 卸载命令
uninstall:
	rmmod $(MODULE_NAME)
```

### 2. 编译驱动模块

在`driver`目录下执行编译命令：

```bash
cd /path/to/driver
make
```

编译成功后，会生成以下文件：
- `zhangsan_led.ko`：驱动模块文件

### 3. 编译设备树覆盖文件

```bash
# 编译设备树覆盖文件
dtc -I dts -O dtb -o led-button-overlay.dtbo led-button-overlay.dts
```

## 三、驱动安装

### 1. 上传文件到开发板

使用`scp`命令将编译好的文件上传到开发板：

```bash
# 上传驱动模块
scp zhangsan_led.ko root@<开发板IP>:/root/

# 上传设备树覆盖文件
scp led-button-overlay.dtbo root@<开发板IP>:/root/
```

### 2. 登录开发板

```bash
ssh root@<开发板IP>
```

### 3. 安装设备树覆盖文件

```bash
# 创建设备树覆盖目录（如果不存在）
mkdir -p /sys/kernel/config/device-tree/overlays/led_button

# 加载设备树覆盖文件
echo led-button-overlay.dtbo > /sys/kernel/config/device-tree/overlays/led_button/path

# 检查设备树加载状态
cat /sys/kernel/config/device-tree/overlays/led_button/status
```

### 4. 安装驱动模块

```bash
# 安装驱动模块
insmod zhangsan_led.ko

# 检查驱动是否加载成功
lsmod | grep zhangsan_led

# 查看设备节点是否创建成功
ls -l /dev/zhangsan_led
```

### 5. 设置设备节点权限

```bash
# 设置设备节点权限，允许普通用户访问
chmod 666 /dev/zhangsan_led
```

## 五、常见问题排查

### 1. 驱动加载失败

```bash
# 查看内核日志，获取详细错误信息
dmesg | grep -i led
```

### 2. 设备节点未创建

检查驱动中的设备创建逻辑，确保：
- `alloc_chrdev_region`调用成功
- `cdev_add`调用成功
- `class_create`和`device_create`调用成功

### 3. 设备树匹配失败

确保：
- 设备树中的`compatible`属性与驱动中的`of_device_id`一致
- 设备树节点已正确加载
- 设备树中的GPIO配置与实际硬件一致

### 4. 权限问题

确保：
- 设备节点权限设置正确
- 应用具有访问设备节点的权限
- 必要时使用root权限运行应用

## 六、驱动卸载

```bash
# 卸载驱动模块
rmmod zhangsan_led

# 卸载设备树覆盖文件
echo -n > /sys/kernel/config/device-tree/overlays/led_button/path
```

## 七、自动加载设置

如果需要驱动在系统启动时自动加载：

```bash
# 将驱动模块复制到系统模块目录
cp zhangsan_led.ko /lib/modules/$(uname -r)/kernel/drivers/misc/

# 更新模块依赖
depmod -a

# 添加到自动加载列表
echo "zhangsan_led" >> /etc/modules
```

## 八、注意事项

1. **内核版本匹配**：驱动必须与开发板内核版本完全匹配
2. **GPIO配置**：根据实际硬件连接修改设备树中的GPIO配置
3. **权限管理**：确保应用具有访问设备节点的权限
4. **日志调试**：使用`dmesg`和`logcat`查看详细日志信息
5. **安全考虑**：在生产环境中，应严格控制设备节点的访问权限
